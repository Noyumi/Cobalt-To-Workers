# Privacy

When you submit a link, the API contacts the source service to locate the media. For downloads through a tunnel, the API streams the file to your browser. Tunnel links expire after five minutes. Treat them like private links while they are valid.

Merging and conversion run in your browser. Local files you open with the remux tool stay on your device.

Cloudflare hosts the website and API and provides the Turnstile challenge. See [Cloudflare's privacy policy](https://www.cloudflare.com/privacypolicy/).

If you choose a custom processing instance, it receives the links you submit and its own privacy policy applies.
