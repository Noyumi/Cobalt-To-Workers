# О Cobalt-To-Workers

Сохраняй видео, фото и аудио с поддерживаемых сайтов. API работает на Cloudflare Workers. Если файл нужно объединить или преобразовать, это сделает твой браузер.

Проект адаптирует [Cobalt от imput](https://github.com/imputnet/cobalt) для Workers. Подробнее в разделе [авторы и лицензии](/about/credits).
