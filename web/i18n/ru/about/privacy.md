# Конфиденциальность

Когда ты отправляешь ссылку, API обращается к исходному сервису, чтобы найти медиафайл. При скачивании через туннель API передаёт файл в браузер. Ссылки на туннели действуют пять минут. Не передавай эти ссылки другим, пока они действуют.

Объединение и преобразование файлов происходят в браузере. Файлы, открытые в инструменте ремуксинга, остаются на твоём устройстве.

Cloudflare размещает сайт и API и предоставляет проверку Turnstile. См. [политику конфиденциальности Cloudflare](https://www.cloudflare.com/privacypolicy/).

Если ты выбираешь сторонний инстанс, он получает отправленные тобой ссылки. В этом случае действует его политика конфиденциальности.
